TA Hub prototype

A clickable prototype of the four main journeys of the MVP, with success and error states. All data is fake. Use the round switcher at the bottom to jump between journeys.

1. Becoming a TA (remote)

  • Student applies on the course page
  • Request sent · team full (error)
  • Professor accepts or rejects
  • Student sees the result

2. Course page in one place

  • Sign in · wrong password
  • Join a course · wrong code
  • Announcements, Telegram group, resources
  • Resources for the assistant (staff view)

3. Assignments and grading

  • TA creates an assignment (question PDF) · error
  • Student submits a PDF · too big · submitted
  • Submissions and deadline extension
  • Grading panel: first student defines the questions
  • Next student: same questions · points above maximum
  • Grade sheet and publishing
  • Student sees own grade · objection · TA answers
  • 403: another student's file

4. Reviews and the AI assistant

  • Professor page with reviews and AI summary
  • Write a review · sent · held for the admin
  • Admin checks hidden reviews
  • Course assistant · chat with sources and a quiz · busy / not in the notes

What is the difference between include and extend in a use case diagram?
include is a step that always happens (for example "Log in" inside "Submit assignment"). extend is an optional step that happens only in some cases (for example "Submit late" extends "Submit assignment").
